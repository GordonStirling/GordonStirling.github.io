Adding Value as a Data Practitioner / 01

OUTPUT ≠ VALUE

This is part 1 of the “Adding Value” series, exploring how data practitioners create value in the real world.

Data practitioners have access to far more data than they will ever process, let alone use. The volume and complexity of data can rob us of clarity, making it easy to lose sight of what we are trying to achieve.

AI tools have enabled data practitioners to analyse more data, faster than ever before. This is hugely powerful when we bake it in to a human centred analysis system. However, when it tempts practitioners to start with the data, rather than with the human it results in... Look at my Shiny Slop! Polished, rapidly produced AI analysis that often lacks purpose, relevance and context. Getting stuck in the volume or complexity of data… or simply getting AI to do it for us can make us forget the fundamental purpose of a data practitioner.

We have to Add Value!

We are producing more outputs than ever before, but how much of this output is adding value?

Meriam-Webster defines value as the relative worth, utility or importance of something. As data practitioners, our work should translate data into actionable insights that prompt behaviour change, enhance decision-making or improve judgements (Martin et al., 2021). Thus, the data itself is not the value.

Value comes from the utility of the insight we create from data.

Dashboards don’t automatically create utility. A dashboard can function exactly as designed. It can use the most valid and reliable data, apply the most elegant and robust analysis techniques and produce beautiful and clear visualisations. Yet it can still be useless if it answers a question no one is asking or produces the insight after the decision has been made.

If our outputs aren’t curated with a specific human centred purpose, they are unlikely to be valuable to the humans they are built to support.

Output ≠ Value.

How we add value as data practitioners is becoming more important than ever before in the rapidly growing information economy. I am going to explore this in more detail throughout this series, but for now I will leave you with this simple question.

What distinguishes an output that just exists from one that adds value?
